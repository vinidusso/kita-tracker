# Kita Finder & Tracker (Neuperlach, München)

Interactive dashboard to track Kindergarten applications starting in September 2027 (Ü3, age 3).

## Key Target Parameters
- Target: Kindergarten (Ü3)
- Entry Date: September 2027 (age 3)
- Area: Neuperlach Süd (81739 München)
- Criteria: High pedagogical quality, proximity, reasonable fee structure
- Mobility: Walking, bicycle, car

## Features
- Distance & commute calculator (walking, biking, driving) from Neuperlach Süd
- Itemized fee breakdowns & total monthly cost estimates (Subsidized vs Private)
- Age group ranges (Kindergarten 3-6 yrs vs. Haus für Kinder 0-10 yrs)
- Certified pedagogical programs & special features (e.g. "Haus der kleinen Forscher", bilingual, fresh on-site kitchen)
- Contact information, website links, opening hours
- Application status workflow & custom notes
- Optional real-time cloud sync with Firebase (or 100% offline via localStorage)
